**两条结论：**

1. **云和那点「近」是假象。** 三家挤在 9–10 km、县城那家 22.1 km 飘红，但时间只差 **13 分钟到 46 分钟**——差的正好就是「多睡半小时」。位置本身不决定取舍，**价格和有没有房才决定**。
2. **仙居只有一家是真坑。** 淡竹乡那四家彼此只差约 100 米、到南门都是 5.2 km / 约 13 分钟，**当成一家来挑、比价就行**，不用比位置。真正的坑是**沐语山居**——它在景区北侧白塔镇，到南门要 10.9 km / 约 22 分钟，南进南出等于每天多开 20 分钟。

**精度说明：** 十家里**只有云城酒店的 22.1 km / 46 分钟是高德实测值**（2026-10-02），其余按 OpenStreetMap 路网里程 + 高德山区实测车速换算——里程已用高德实测值校准，误差在 1% 内；时间按 OSRM 估值乘 1.44（山区）／2.4（县城红绿灯）系数换算，**出行前请在自己的导航里复核**。

## 两条重要的更正（推翻早前版本）

1. **朱潭山是要门票的，「免费」只在 7:30 之前。**
   90 元联票里收费的是**朱潭山、鼎湖峰、倪翁洞、仙都观**；岩宕书房、小赤壁本来就免费。
   「仙都免费版」的真正原理是**赶在 7:30 收费闸门关前进场**，不是「朱潭山不要票」。
   你们 11:00 到，进朱潭山就要买票（90/人，6 人 540），且**国庆需实名预约**（"仙都旅游"公众号 / 浙里办）。
   文档里给了三个选项：① 走免费机位看牵牛 ② 砍掉朱潭山只走岩宕书房 + 小赤壁 ③ 买票（联票 130 含六大景点，单买主景区 90）。
2. **云和上山路比传说中好开。**
   实测 22.3 km / 46 分钟里只有 10 个转向指令，最长一段 6.1 km 不用拐弯；584 m 落差平均坡度只有 2.6%。
   不是密集发卡弯——**要防的是没灯、会车、晨雾，不是弯道**。
