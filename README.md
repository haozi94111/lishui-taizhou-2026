# 丽水台州三日自驾 · 2026 国庆

杭州往返，10/4 出发 10/6 回，6 人 3 间房。

云和梯田和神仙居是定死的，唯一要选的是 **10/4 那天去哪**——那天中雨，所以给了三条走法。

## 内容

- **第一部分 · 定方案** — 三个方案对比表、A/B 花费对比、三条走法的完整时刻表、8 个备选景点
- **第二部分 · 照着走** — 10/5、10/6 的时刻表（三个方案共用）
- **第三部分 · 后勤** — 民宿电话表（33 家，附高德链接）、门票与优惠政策、天气、出发前必办清单

## 怎么用

在手机浏览器里打开即可：目录行可以点着跳转，点电话号码会复制，点民宿名会打开高德搜位置。

## 文件说明

`index.html` 是完全自包含的单文件，无本地依赖。唯一的联网请求是 Google Fonts，拉不到会自动回退到系统字体。

源文件不在这里（改动请回到本地 `lishui-taizhou.html`，再跑 `build_share.py` 重新生成）。
