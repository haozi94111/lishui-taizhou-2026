# 丽水台州三日自驾 · 2026 国庆

杭州往返，10/4 出发 10/6 回，6 人 3 间房。**方案已定，这份文档只写这一条路。**

10/4 走缙云仙都「免费版」——不去鼎湖峰，提前办车辆报备，自驾直达朱潭山、岩宕书房、小赤壁；当晚到云和，第二天看梯田日出，第三天神仙居南上南下后回杭州。

## 内容

- **第一部分 · 定案** — 三天骨架表、为什么是这个走法、钱花在哪（能省 1200–1900 的两处标注）
- **第二部分 · 照着走** — 三天各一张时刻表，每天再配一张「导航搜什么 · 车停哪 · 多少钱」
  - 10/4：朱潭山 / 岩宕书房 / 小赤壁三点导航停车 + **车辆报备怎么办** + 仙都平价饭店表（含可帮报备的两家）
  - 10/5：九曲云环 D 区停车场、观云索道、坑根石寨、七星墩 + 景交车 1/2 号线票价
  - 10/6：南门 3 号停车场 + 官方停车费分段标准 + 返程收费站选择
- **第三部分 · 后勤** — 住宿实价与电话表（27 家，携程真实报价）、门票、日出与云海查询工具、顺路平价吃与免费景点、出发前必办 6 件事

## 数据来源

- 房价：携程 2026-10-02 对 **10/4–10/5** 的实际报价（1 间 2 人），不是民宿名录上的虚价
- 餐厅评分 / 人均 / 评价数：大众点评（账号已登录抓取）
- 报备与管控：缙政办发[2017]116 号、仙都景区管委会 2026-09-30 国庆公告
- 索道 / 开放时间 / 停车费：景区官方票务页与官方公众号国庆 Q&A

## 怎么用

在手机浏览器里打开即可：目录行可以点着跳转，点电话号码会复制，点民宿名和导航关键词会打开高德搜位置。

## 已知的不确定项

文档里用红色 callout 标出的、需要打电话确认的三件事：

1. **云和梯田的「日出追光巴士」首班时间**——官方只提了名字没给时刻表，这直接决定 10/5 早上能不能不自驾上山
2. **九曲云环到七星墩能不能自驾**——官方零信息，网友说法矛盾，关系到 6 人 1200 元索道费
3. **神仙居南登山步道是否开放**——北步道确认封闭，南步道只有一条已失效的投诉为证，关系到 720 元索道费
