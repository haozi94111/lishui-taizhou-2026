# 丽水台州三日自驾 · 2026 国庆

杭州往返，10/4 出发 10/6 回，6 人 3 间房。**方案已定，这份文档只写这一条路。**

10/4 走缙云仙都「免费版」——不去鼎湖峰，提前办车辆报备，自驾直达朱潭山、岩宕书房、小赤壁；当晚到云和，第二天看梯田日出，第三天神仙居南上南下后回杭州。

10/4 早上要先绕**绍兴后梅小区接人**（+40 km / +40 min），所以出发定在 05:30。

## 内容

- **第一部分 · 定案** — 三天骨架表、为什么是这个走法、钱花在哪（能省 720–1440 的标注）
- **第二部分 · 照着走** — 三天各一张时刻表，每天再配一张「导航搜什么 · 车停哪 · 多少钱」
  - 10/4：绍兴接人 → 朱潭山 / 岩宕书房 / 小赤壁三点导航停车 + **车辆报备怎么办** + 仙都平价饭店表（含可帮报备的两家）
  - 10/5：九曲云环 D 区停车场、观云索道、坑根石寨、七星墩 + 景交车 1/2 号线票价 + 云和梯田吃什么（大众点评 12 家）
  - 10/6：南门 3 号停车场 + 官方停车费分段标准 + 返程收费站选择 + 神仙居/白塔镇吃什么（大众点评 19 家）
- **第三部分 · 后勤** — 住宿实价与电话表（携程 + 美团双源对照）、门票、日出与云海查询工具、顺路平价吃与免费景点、出发前必办 6 件事

## 已知的不确定项

文档里用红色 callout 标出的、需要打电话确认的三件事：

1. **云和梯田的「日出追光巴士」首班时间**——官方只提了名字没给时刻表（携程攻略写 20 元/人），这直接决定 10/5 早上能不能不自驾上山
2. **九曲云环到七星墩能不能自驾**——官方零信息，但携程点评里有人写明「返回九曲云环游客中心取车，自驾到七星墩差不多二十分钟」，按此大概率能自驾，关系到 **720 元**索道费
3. **神仙居南登山步道是否开放**——北步道确认封闭，南步道只有一条已失效的投诉为证，关系到 720 元索道费
