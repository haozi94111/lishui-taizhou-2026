## 两条重要的更正（推翻早前版本）

1. **朱潭山是要门票的，「免费」只在 7:30 之前。**
   90 元联票里收费的是**朱潭山、鼎湖峰、倪翁洞、仙都观**；岩宕书房、小赤壁本来就免费。
   「仙都免费版」的真正原理是**赶在 7:30 收费闸门关前进场**，不是「朱潭山不要票」。
   你们 11:00 到，进朱潭山就要买票（90/人，6 人 540），且**国庆需实名预约**（"仙都旅游"公众号 / 浙里办）。
   文档里给了三个选项：① 走免费机位看牵牛 ② 砍掉朱潭山只走岩宕书房 + 小赤壁 ③ 买票（联票 130 含六大景点，单买主景区 90）。
2. **云和上山路比传说中好开。**
   实测 22.3 km / 46 分钟里只有 10 个转向指令，最长一段 6.1 km 不用拐弯；584 m 落差平均坡度只有 2.6%。
   不是密集发卡弯——**要防的是没灯、会车、晨雾，不是弯道**。
